## 📌 Overview

**Friend Pulse** is a modern web application designed to help you stay connected with your friends and maintain meaningful relationships.

It allows users to track how long it has been since they last contacted each friend and helps ensure you never lose touch with important people in your life.

---

## 📖 Short Description

Friend Pulse is a responsive **relationship management web application** that helps users monitor and nurture their personal and professional connections.

It tracks:
- Last contact time
- Friend status based on custom goals
- Relationship progress
- Upcoming catch-up needs

It also includes powerful tools like timelines, detailed profiles, and insightful analytics dashboards.

---

## ✨ Key Features

### 📋 Smart Friend Management & Profiles
- Browse all friends in a clean UI
- Detailed profiles (photo, bio, tags, email, history)
- Contact status based on goal tracking system
- Full profile view for each friend

---

### 📅 Interactive Timeline Page
- Sortable timeline of all interactions
- Track last contact dates
- Plan future catch-ups easily

---

### 📊 Insightful Stats Dashboard
- Visual analytics using Recharts
- Contact frequency insights
- Relationship health overview
- Status distribution charts

## ⚙️ Getting Started (Run Locally)

```bash

# 2. Navigate to project folder

# 3. Install dependencies
